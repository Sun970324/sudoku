Zeigende Kandidaten

Zeigendes Paar · Gesperrte Kandidaten · Schnittmenge · Pointing Pair

Zeigende Kandidaten (Pointing Pair) sind eine Sudoku-Technik: Liegen alle Kandidaten einer Ziffer in einem Block in nur einer Zeile oder Spalte, streichst du diese Ziffer im Rest dieser Linie außerhalb des Blocks.

So sieht Zeigende Kandidaten aus

Das Bild zeigt nur die Ziffer 4. In Block 1 kann die 4 nur in R2C1 oder R2C3 stehen, beide in Zeile 2. Die zwei Kandidaten zeigen auf eine Linie, daher auch der Name Pointing Pair.

4 im Block (nur Zeile 2) Hier wird die 4 gestrichen Nicht betroffene 4en

Warum klappt das?

Block 1 braucht eine 4, und dafür gibt es nur zwei Felder in Zeile 2. Also liegt die 4 von Zeile 2 in Block 1.

Zeile 2 hat nur Platz für eine 4. Die übrigen Felder von Zeile 2 außerhalb des Blocks (Spalte 5 und 8) können also keine 4 sein. Streich dort die 4.

So findest du Zeigende Kandidaten

  1. Wähle einen Block und eine Ziffer.
  2. Prüfe, ob alle ihre Kandidaten im Block in einer Zeile oder Spalte liegen.
  3. Wenn ja, streich die Ziffer auf derselben Linie außerhalb des Blocks.

Mit drei Kandidaten im Block klappt es genauso, solange alle auf einer Linie liegen.

Häufige Fragen

Was ist der Unterschied zur Block-Linien-Reduktion?

Zeigende Kandidaten starten im Block und streichen auf der Linie. Die Block-Linien-Reduktion startet in der Linie und streicht im Block. Nur die Richtung ist umgekehrt.

Und wenn im Block nur ein Kandidat ist?

Dann ist dieses Feld die Lösung. Das ist ein Versteckter Single, trag die Ziffer einfach ein.

Klappt das auch mit Spalten?

Ja. Liegen alle Kandidaten im Block in einer Spalte, streichst du die Ziffer in dieser Spalte außerhalb des Blocks.
