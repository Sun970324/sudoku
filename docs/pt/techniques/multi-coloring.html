Multi-Coloring

Multicoloração · Coloração múltipla

O Multi-Coloring (multicoloração) é uma técnica de sudoku que pinta dois grupos separados de um mesmo número e, quando uma cor de um grupo vê uma cor do outro, remove esse número de qualquer célula que veja as cores opostas dos dois grupos.

Números a observar
Um só
O que você precisa
Dois grupos com duas cores cada
O que remover
Células que veem as duas cores opostas

O padrão Multi-Coloring

O diagrama mostra só o número 3. O grupo 1 é a coluna 1, onde os dois candidatos são R2C1 (verde) e R7C1 (amarelo). O grupo 2 é a coluna 5, com R7C5 (azul) e R3C5 (roxo). R7C1 amarelo e R7C5 azul estão na mesma linha 7.

Grupo 1 verde Grupo 1 amarelo Grupo 2 azul Grupo 2 roxo Células onde o 3 sai

Por que funciona?

Amarelo (R7C1) e azul (R7C5) estão na mesma linha, então não podem ser 3 ao mesmo tempo. Pelo menos uma dessas cores está errada.

Amarelo erradoA cor oposta no grupo 1, verde (R2C1), é 3.
Azul erradoA cor oposta no grupo 2, roxo (R3C5), é 3.

De qualquer jeito, verde ou roxo é sempre 3. Uma célula que vê os dois não pode ser 3. R3C3 está no mesmo bloco de R2C1 e na mesma linha de R3C5, e R2C6 está na mesma linha de R2C1 e no mesmo bloco de R3C5. Remova o 3 das duas.

Como encontrar Multi-Coloring

  1. Pinte grupos de um número como no Simple Coloring. Dê a cada grupo separado suas próprias duas cores.
  2. Procure um lugar onde uma cor de um grupo vê uma cor do outro.
  3. Remova o número das células que veem as duas cores opostas.

Dúvidas comuns

Qual a diferença para o Simple Coloring?

O Simple Coloring olha as duas cores dentro de um grupo. O Multi-Coloring olha juntas as cores de dois grupos separados.

E se houver três grupos ou mais?

Junte os grupos de dois em dois e use o mesmo método.

Dá para explicar com uma Cadeia X?

Dá. Acrescente o elo fraco que une os dois grupos e eles viram uma única Cadeia X longa.
