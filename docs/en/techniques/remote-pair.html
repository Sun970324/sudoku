Remote Pair

A Remote Pair is a chain of cells that all hold the same two candidates and see each other in turn. Any cell that sees two cells of opposite value along the chain loses both digits.

Cells needed
Several cells with the same two candidates
How they link
Each sees the next through a line or box
What to remove
Cells that see two opposite cells

The Remote Pair pattern

Four cells, all holding 4 and 9. From R2C1 through R2C6 and R7C6 to R7C3, each cell sees the next. Two cells that see each other cannot match, so 4 and 9 alternate along the chain.

Cells with the same value Cells with the opposite value 4 or 9 to remove Candidates that stay

Why does this work?

Cells that see each other cannot hold the same digit, so values alternate along the chain.

If R2C1 is 4R2C6 is 9, R7C6 is 4 and R7C3 is 9.
If R2C1 is 9R2C6 is 4, R7C6 is 9 and R7C3 is 4.

Either way, the ends R2C1 and R7C3 are one 4 and one 9. A cell that sees both ends cannot be 4 or 9. R2C3 shares a row with R2C1 and a column with R7C3, so it loses 4 and 9. R8C1 shares a column with R2C1 and a box with R7C3, so it loses its 4.

How to find the Remote Pair

  1. Find every cell whose only candidates are the same two digits.
  2. Link the ones that see each other into a chain.
  3. Color the chain in two alternating colors.
  4. Remove both digits from cells that see two cells of different colors.

Common questions

How many cells do I need?

Four or more to be useful. With two, a naked pair already does the job.

What about a cell that sees two cells of the same color?

Those two cells hold the same digit, so nothing is removed there. Only a cell that sees both colors loses the digits.

How does it relate to an XY-Chain?

It is an XY-Chain where every cell holds the same two digits, which makes it easier to spot.
