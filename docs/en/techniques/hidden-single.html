Hidden Single

A Hidden Single is a digit that has only one possible cell in a row, column or box. Fill that cell with the digit.

Digits to watch
One
Where to look
One row, column or box
What to do
Fill the one cell left

The Hidden Single pattern

The diagram shows where 4 can go in box 1. The 4 in R1C7 rules out row 1, the 4 in R6C2 rules out column 2, and the 4 in R3C5 rules out row 3. Only R2C1 is left.

4s already placed The only cell left for 4

Why this cell?

Box 1 needs a 4. Of its empty cells, the ones in row 1, column 2 and row 3 already have a 4 on the same line.

So box 1 can only take its 4 in R2C1. Fill it in, even if the cell has other candidates. They hide the answer, which is why it is called a hidden single.

How to find the Hidden Single

  1. Pick a row, column or box and one digit.
  2. Follow the lines where that digit is already placed and cross off the cells they block.
  3. If one cell is left, fill it with the digit.

Boxes are the easiest place to start. Take one digit around the whole grid and look for a box with a single cell left.

Common questions

How is it different from a naked single?

A hidden single starts from a digit: it fits in only one cell. That cell may still have several candidates.

Does it work in rows and columns?

Yes. If a digit has only one cell in a row or column, fill it in the same way.

Which digit should I start with?

Start with digits that are already placed many times. They block more lines, so the last cell shows up quickly.
