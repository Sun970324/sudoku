SUDOKU TECHNIQUES

Sudoku Techniques

The solving techniques behind Sudoku League's hints and Technique Practice, each with an example board, how to find it and why the eliminations are safe.

Singles

  • Naked SingleSole CandidateA Naked Single is a cell with only one digit left that can go in it. It is the most basic sudoku technique: fill the cell with that digit.
  • Hidden SingleA Hidden Single is a digit that has only one possible cell in a row, column or box. Fill that cell with the digit.

Basics

  • Naked PairA Naked Pair is two cells in the same row, column or box whose only candidates are the same two digits. Those two digits can then be removed from every other cell in that row, column or box.
  • Hidden PairA Hidden Pair is two digits that can only go in the same two cells of a row, column or box. Every other candidate in those two cells can then be removed.
  • PointingIntersection · Pointing Pair · Locked CandidatesPointing is when every candidate for a digit inside one box lies in a single row or column. That digit can then be removed from the rest of that row or column outside the box.
  • ClaimingIntersection · Box/Line ReductionClaiming is when every candidate for a digit in one row or column lies inside a single box. That digit can then be removed from the other cells of that box.

Fish

  • X-WingAn X-Wing is when a digit's candidates in two rows sit in exactly the same two columns. That digit can then be removed from every other cell in those two columns.
  • Finned X-WingA Finned X-Wing is an X-Wing with one or two extra candidates, the fin, on one of its rows. The digit can be removed from cells in an X-Wing column that share a box with the fin.
  • Sashimi X-WingA Sashimi X-Wing is an X-Wing with one corner missing and candidates (the fin) next to it in the same box. The digit can be removed from cells in the missing corner's column that share a box with the fin.
  • SwordfishA Swordfish is when a digit's candidates in three rows all lie within the same three columns. That digit can then be removed from every other cell in those three columns.
  • JellyfishA Jellyfish is when a digit's candidates in four rows all lie within the same four columns. That digit can then be removed from every other cell in those four columns.

Single-digit patterns

  • SkyscraperA Skyscraper is two columns where a digit has exactly two candidates and one end of each sits in the same row. The digit can then be removed from any cell that sees both of the other ends.
  • 2-String KiteTwo-String KiteA 2-String Kite is a row and a column, each with exactly two candidates for a digit, that meet in one box. The digit can be removed from any cell that sees both far ends.

Coloring

  • Simple ColoringSingle ChainsSimple Coloring links the lines and boxes where a digit has exactly two candidates and colors the cells in two alternating colors. Any cell that sees both colors cannot hold that digit.
  • Multi-ColoringMulti-Coloring colors two separate clusters of one digit. When a color of one cluster sees a color of the other, any cell that sees both opposite colors cannot hold that digit.

Chains

  • Remote PairA Remote Pair is a chain of cells that all hold the same two candidates and see each other in turn. Any cell that sees two cells of opposite value along the chain loses both digits.
  • X-ChainAn X-Chain links one digit's candidates with strong and weak links in turn. Any cell that sees both ends of the chain cannot hold that digit.
  • XY-ChainAn XY-Chain is a chain of two-candidate cells, each passing one digit to the next, whose two ends share the same digit. That digit can be removed from any cell that sees both ends.
  • AICAlternating Inference ChainAn AIC (Alternating Inference Chain) links candidates of several digits with strong and weak links in turn. One end of the chain must be true, so any candidate that sees both ends can be removed.
  • ALS ChainALS-AICAn ALS Chain (ALS-AIC) is an AIC that uses an almost locked set (ALS), a group of cells with one more candidate than cells, as one of its links. One end must be true, so any candidate that sees both ends can be removed.

Wings

  • XY-WingY-WingAn XY-Wing is three cells with two candidates each, joined through a middle cell. The digit the two outer cells share can be removed from any cell that sees both of them.
  • XYZ-WingAn XYZ-Wing is a middle cell with three candidates and two cells it sees with two candidates each, all three sharing one digit. That digit can be removed from any cell that sees all three.
  • W-WingA W-Wing is two cells with the same two candidates, joined by a strong link on one of those digits. The other digit can be removed from any cell that sees both cells.
  • WXYZ-WingA WXYZ-Wing is four cells whose candidates add up to only four digits, where just one of those digits sits in cells that do not all see each other. That digit can be removed from any cell that sees every cell holding it.

Uniqueness

  • Hidden Unique RectangleHidden RectangleA Hidden Unique Rectangle is four cells forming a rectangle on two digits, where one digit has only two candidates in the opposite corner's row and column. Because the puzzle has one answer, the other digit can be removed from that corner.
  • BUG+1Bivalue Universal GraveBUG+1 applies when every empty cell has two candidates except one cell with three. That cell is the digit that appears three times in its row, column or box.

Advanced patterns

  • Sue de CoqSue de Coq is when the candidates of cells where a box and a line overlap are split between a cell on the line and a cell in the box. Each side's digits can then be removed from the rest of the line and the rest of the box.
  • Triple FireworkFireworkA Triple Firework is a cell in a box plus one cell in the same row and one in the same column outside the box, which must share three digits. Every other candidate can be removed from those three cells.
